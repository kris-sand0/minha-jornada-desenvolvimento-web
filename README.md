# Minha Jornada no Desenvolvimento Web

Projeto desenvolvido como parte do desafio prático da DIO (Digital Innovation One), com o objetivo de aplicar os conhecimentos adquiridos durante os estudos de HTML.

## Sobre o projeto

Uma página web desenvolvida utilizando HTML, apresentando minha jornada de aprendizado no desenvolvimento Front-end.

## Tecnologias utilizadas

- HTML5

## Conceitos praticados

- Estrutura básica de um documento HTML
- Títulos e parágrafos
- Formatação de textos
- Listas ordenadas e não ordenadas
- Links externos
- Subscrito e sobrescrito
- Citações e abreviações
- Tags HTML semânticas e de formatação

## Objetivo

Praticar os fundamentos do HTML e desenvolver minha experiência na construção de páginas web.

## Autor

Desenvolvido como parte da minha jornada de aprendizado em desenvolvimento Front-end.
